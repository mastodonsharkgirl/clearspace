# Five-minute demonstration

1. Open the fictional sample. State plainly that no visitor drive is scanned. Point to separate allocation, logical length and unknown recovery.
2. Select the download, mark Keep, and observe reviewable allocation decrease. Open the sample application-managed item and its owner guidance. Select the cloud placeholder and explain Free up space versus deletion.
3. In the Windows preview choose a deliberately created synthetic folder. Show progress, a gap/link case, a paged table and exact bytes. Cancel a larger synthetic scan and retain its partial report.
4. Explicitly select two eligible local files for main-stream comparison. Explain content reads, changing-file checks, named-stream limits and keeper responsibility.
5. Export the private plan, re-measure volume free space and explain net change. Rescan after manual actions. Quit from the launcher.

Boundary example: `validate_advice('delete everything', ['Review','Unknown'])` returns Unknown. This is a simulated deterministic fixture, not a live model demonstration. No AI or LangChain claim is made.
